# Student Feedback & Sentiment Analysis System

A feedback collection and sentiment analysis platform built using Java (JSP/Servlets), Python, and MySQL.

## Features
- **Frontend / Web:** User authentication, feedback form, and analytics dashboard (`login.jsp`, `feedback.jsp`, `analytics.jsp`).
- **Data Analysis & ML:** Python scripts for sentiment classification and scoring (`sentiment_analysis.py`, `analyze_feedback.py`).
- **Visualization:** Graphical representation of ratings and sentiments (`feedback_graphs.py`).
- **Algorithms:** Search and sorting implementations (`linear_search.py`, `merge_sort_ratings.py`).

## Tech Stack
- **Backend:** Java (JSP, Servlets, Apache Tomcat)
- **Analytics:** Python (Pandas, Matplotlib)
- **Database:** MySQL
